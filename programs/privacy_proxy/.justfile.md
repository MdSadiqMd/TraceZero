# Just Command Reference

Quick reference for available Just recipes.

## Installation

```bash
# macOS
brew install just

# Linux/WSL
cargo install just

# Windows
scoop install just
# or
cargo install just
```

## Basic Commands

| Command | Description |
|---------|-------------|
| `just` | Build programs (default) |
| `just build` | Build with IDL verification |
| `just list` | Show all available commands |

## Development

| Command | Description |
|---------|-------------|
| `just watch` | Watch mode - rebuild on changes |
| `just check` | Check code without building |
| `just fmt` | Format Rust code |
| `just lint` | Lint with clippy |
| `just full-check` | Format, lint, build, test |

## Testing

| Command | Description |
|---------|-------------|
| `just test` | Run all tests |

## Deployment

| Command | Description |
|---------|-------------|
| `just deploy-devnet` | Deploy to devnet |
| `just deploy-mainnet` | Deploy to mainnet (with confirmation) |

## IDL Management

| Command | Description |
|---------|-------------|
| `just fix-idl` | Fix IDL addresses |
| `just verify-idl` | Verify IDL addresses |

## Utilities

| Command | Description |
|---------|-------------|
| `just clean` | Clean build artifacts |
| `just show-addresses` | Show program addresses |
| `just ci-build` | CI build (strict mode) |

## Examples

### Development Workflow

```bash
# Start watch mode
just watch

# In another terminal, make changes to code
# Watch mode will automatically rebuild

# When ready to test
just test

# Format and lint before commit
just fmt
just lint
```

### Deployment Workflow

```bash
# Build and verify
just build

# Deploy to devnet for testing
just deploy-devnet

# After testing, deploy to mainnet
just deploy-mainnet
```

### CI Workflow

```bash
# Run full CI checks
just ci-build
```

## Tips

- **Tab completion**: Just supports shell completion. See [docs](https://github.com/casey/just#shell-completion-scripts)
- **Dry run**: Use `just --dry-run <recipe>` to see what would be executed
- **Verbose**: Use `just --verbose <recipe>` for detailed output
- **Choose**: Run `just --choose` to interactively select a recipe

## Why Just?

Just is better than Make for this use case:

- ✅ Better error messages
- ✅ Colored output
- ✅ Cross-platform (works same on macOS/Linux/Windows)
- ✅ Simpler syntax
- ✅ Built-in help (`just --list`)
- ✅ No weird tab/space issues
- ✅ Modern and actively maintained
